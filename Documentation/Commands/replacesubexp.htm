replacesubexp

 

Can be used to disable or enable the evaluation of subexpressions in Prospa strings.

 

Syntax

 

replacesubexp("true"/"false") 

 

 

Description

 

When the argument is set to true string subexpressions – delineated by a pair of $ signs will be processed and replace with the evaluation. If set to false they will be left untouched. The false setting can be useful when saving a string with a subexpression for later evaluation.

 

Example

 

replacesubexp("false")

b = 45

a = "$b*3$"

pr a

replacesubexp("true")

b = 45

a = "$b*3$"

pr a

 

This outputs

 

  a = $b*3$

 

  a = 135
