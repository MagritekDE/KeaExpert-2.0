plotcallback

 

This allows the scroll-wheel, move and double click actions in 1D plots to be overridden. Just pass a user defined macro to use instead. An empty string will revert to the default action 

 

Syntax

 

current_macro = plotcallback(function_to_replace [,callback_macro])

 

function_to_replace ... one of plot1DScale, plot1DMove, plot1DDblClick (STR)

callback_macro ........ the name of the macro to call. (STR)

 

 

Description

 

Sometimes the built-in operation of the plot is not sufficient. In this case you can override these defaults with your own procedures.

 

Example

 

In the 1DPlotAnalyser there is an option in the tool bar () to move a single trace in a stacked plot left or right. This is done using this macro:

 

procedure(moveTraceHorizontally)

 

   callback = plotcallback("plot1DMove")

   if(callback == "")

      func1d("drag plot")

      plotcallback("plot1DMove","userPlotMove")

      setpar(0,3,"checkitem",25)

   else

      plotcallback("plot1DMove","")

      setpar(0,3,"uncheckitem",25)

   endif

 

endproc()

 

The userPlotMove macro is shown below. Each time the mouse is dragged it calls this function with the new cursor positions (xc, yc) and old one (xlast, ylast). Based on the difference between xc and xlast it will rotate the trace data horizontally and then refresh the display.

 

procedure(userPlotMove, xc, yc, xlast, ylast)

 

   pt = curplot("1d")

   tc = pt->curtrace()

 

# Get the data

   (x,y) = pt->getdata("all")

   if(x == null)

     message("Error","No 1D plot data","error")

     return()

   endif

 

# Work out index

   xc = findindex(x,xc)

   xl = findindex(x,xlast)

 

# Rotate the data

   delx = xl - xc

   if(abs(delx) >= 1)

 

      yn = rotate(y,-delx,0)

      pt->parent->draw("false")

      pt->autorange("off")

      tc->setdata(struct(x,yn))

      pt->parent->draw("true")

 

    endif

 

endproc()
